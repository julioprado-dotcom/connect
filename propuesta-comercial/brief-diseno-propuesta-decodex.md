## Estructura del Documento (10 secciones)

### PORTADA
- Logo DECODEX grande y centrado
- Título: "Propuesta Comercial"
- Subtítulo: "Sistema de Inteligencia Mediática Institucional"
- Fondo: Navy (#0F2027) o degradado Navy → Teal
- Limpia, minimalista, sin imagen decorativa

### SECCIÓN 1: El Problema
- Layout: texto principal con un dato visual destacado (ej: "53 fuentes", "24/7")
- Usar un sidebar o callout con color Orange para el dato clave

### SECCIÓN 2: Qué es DECODEX
- Tagline destacado: "Decodificamos la realidad. De datos dispersos a información inteligible."
- Layout: texto + icono/símbolo del sistema
- Fondo alternado (Light #F4F8FC)

### SECCIÓN 3: ONION200
- Diferenciación visual clara vs. "IA genérica"
- Layout: dos columnas o comparación visual (ONION200 vs. ChatGPT genérico)
- Usar iconos o ilustraciones sutiles

### SECCIÓN 4: Las 4 Capas
- **Diagrama de flujo visual** horizontal o vertical: Captura → Indicadores → Procesamiento → Entrega
- Cada capa con ícono, título, descripción breve
- Usar los colores de marca para diferenciar cada capa
- Esta sección DEBE ser visual, no solo texto

### SECCIÓN 5: Los 11 Ejes Temáticos
- Layout de **grilla visual** (grid): 11 cards o bloques con el nombre de cada eje
- Cada eje puede tener un color o icono distintivo
- NO es una tabla plana: debe ser visualmente atractivo
- Posible layout: 4 columnas × 3 filas (con la última fila centrada)

### SECCIÓN 6: Catálogo de Productos
- **Tabla principal** con los 10 productos premium (nombre, frecuencia, precio, descripción breve)
- Separación visual clara entre Premium y Gratuitos
- Los 3 gratuitos en un bloque secundario más sutil
- Precios en Bs destacados con color Orange

### SECCIÓN 7: Tres Planes de Cobertura
- **Tres cards/columnas** lado a lado (modelo pricing table)
- Plan Independiente (izquierda, más simple)
- Plan Profesional (centro, recomendado — destacar con borde Blue o badge)
- Plan Institucional (derecha, premium — destacar con Navy)
- Cada card con: precio grande, lista de incluye (con checks), buzones, canales
- Fondo: Light o White con bordes de marca

### SECCIÓN 8: Segmentos de Cliente
- Layout limpio: tabla o grilla con segmento + descripción + plan recomendado
- No necesita ser la sección más visual

### SECCIÓN 9: Metodología
- **Sub-sección: Proceso** — Diagrama de flujo (reutilizar estilo de Capa 4)
- **Sub-sección: Tratamiento Periodístico** — 6 badges/tarjetas con los 6 tipos (Informativo, Analítico, Elogioso, Crítico, Agresivo, Ambiguo). Cada uno con color. Usar estos colores del sistema:
  - Informativo: `#06b6d4` (cyan)
  - Analítico: `#8b5cf6` (violet)
  - Elogioso: `#10b981` (emerald)
  - Crítico: `#f43f5e` (rose)
  - Agresivo: `#ef4444` (red)
  - Ambiguo: `#f59e0b` (amber)
- **Sub-sección: 9 Principios** — Grid 3×3 de tarjetas pequeñas, cada una con número + nombre + 1 frase clave
- Fondo alternado

### SECCIÓN 10: Ventajas Competitivas
- **Tabla comparativa** (DECODEX vs. Clipping tradicional) — debe ser visual con checks y crosses o iconos
- **Ventajas específicas** — 4 bloques con ícono + título + descripción breve
- Cierre: el párrafo final sobre fondo Navy con texto blanco

## Reglas de Diseño

1. NO usar emojis decorativos en el documento
2. NO usar "SaaS", "observatorio", "sentimiento", "reach", "insights", "stakeholders"
3. NO usar imágenes de stock genéricas (personas mirando pantallas, manos tecleando, etc.)
4. NO usar degradados excesivos ni efectos 3D
5. SÍ usar datos y números como elementos visuales
6. SÍ usar los colores de marca de forma consistente
7. SÍ usar iconos minimalistos (line icons) para diferenciar secciones
8. SÍ mantener jerarquía tipográfica clara (H1 > H2 > H3 > body)
9. SÍ dejar espacio en blanco — no amontonar contenido
10. Cada página debe tener un punto focal claro (un dato, una grilla, un diagrama)
